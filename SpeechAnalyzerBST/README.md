# Speech Analyzer BST

Projeto em Java desenvolvido para a disciplina de Estrutura de Dados.  
O programa utiliza uma **árvore binária de busca (BST)** para armazenar e analisar palavras de um discurso.

## Funcionalidades
- Carregar discurso a partir de um arquivo `.txt`
- Contar o total de palavras
- Buscar ocorrência de uma palavra
- Listar todas as palavras em ordem alfabética
- Verificar sinais de depressão (comparando com `PalavrasDepressao.txt`)
- Estatísticas do texto:
  - Palavra mais frequente
  - Quantidade de palavras únicas
  - Quantidade de palavras com 3 letras

## Tecnologias
- Java 11+
- Estruturas de Dados: Árvore Binária de Busca (BST)
- Manipulação de arquivos `.txt`
